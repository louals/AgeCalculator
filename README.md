# AgeCalculator

## Overview

Age calculator: enter a birthday and see your age in years, months, and days.

## Tech Stack

Web

## Features

- Years, months, and days breakdown

## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

```bash
git clone https://github.com/<your-username>/AgeCalculator.git
cd AgeCalculator
```
Open `index.html` in your browser. No build step required.
